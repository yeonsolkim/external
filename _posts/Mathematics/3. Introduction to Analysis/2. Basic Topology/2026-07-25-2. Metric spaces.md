**Definition 2.2.1.** Let $P$ and $R$ be a point sort and a scalar sort, respectively. Then, we let

$$\mathcal L_{\mathrm{met}} = \left\{ P,R,\, 0_R,+_R,<_{R},\, d \right\},$$

where $0_R$ is a constant of sort $R, +_R:R^2\to R, <_{R}\subseteq R^2,$ and $d:P^2\to R$ is a function symbol. An $\mathcal L_{\mathrm{met}}$-structure therefore has the form

$$\mathcal M = \left( M,S;\, 0^{\mathcal M},+^{\mathcal M},<^{\mathcal M},d^{\mathcal M} \right),$$

where $M$ is the set of points and $S$ is the set in which distances take their values.<br>
&emsp; Suppose that the scalar sort is interpreted as the ordered additive structure of the real numbers. That is,

$$\mathcal M_{(M,d)} = \bigl(M,\mathbb R;\,0,+,<,d\bigr).$$

$\mathcal M_{(M,d)}$ is a *metric space* if it satisfies the following sentences, where $x,y,z$ range over the point sort $P$:

1. $\forall x,y\ (0\le d(x,y)),$
2. $\forall x,y\ (d(x,y)=0\leftrightarrow x=y),$
3. $\forall x,y\ (d(x,y)=d(y,x)),$
4. $\forall x,y,z\ \left(d(x,z)\le d(x,y)+d(y,z)\right).$
{:marker-prefix="M" }

In this case, $d$ is called the *metric* on $M.$<br>
<br>

**Definition 2.2.2.** A set $S\subseteq \mathbb R^k$ is *convex* if 

$$\forall x,y\in S\ \forall \lambda \in (0,1)\ \left( \lambda x + (1-\lambda)y\in S\right).$$

<br>

**Example 2.2.3.** Let $a_i<b_1$ for $i=1,\dots, k,$ and define $S$ to be the set of all points $x=(x_1,\dots,x_k)$ in $\mathbb R^k$ such that $x_i\in [a_i,b_i]$ for $i=1,\dots, k.$ The set $S$ is called a $k$-*cell*.<br>
&emsp; Let $x,y\in S, \lambda \in (0,1),$ and $z_i = \lambda x_i + (1-\lambda)y_i.$ Since 

$$ \lambda a_i\le \lambda x_i \le \lambda b_i\quad \text{and} \quad (1-\lambda)a_i\le (1-\lambda)y_i\le (1-\lambda)b_i,$$

we have $a_i\le z_i\le b_i,$ so that $z_i\in S.$ Thus $S$ is convex.<br>
&emsp; In general, $k$-cells are convex.

<br>


**Definition 2.2.4.** Let $(M,d)$ be a metric space. For $a\in M$ and $r\in\mathbb R_{>0}$, the *open ball* of radius $r$ centered at $a$ is defined externally by

$$B_r(a)=\{x\in M:d(x,a)<r\}.$$

The corresponding *closed ball* and *punctured open ball* are

$$\overline B_r(a)=\{x\in M:d(x,a)\le r\}$$

and

$$B_r^{\ast}(a)=B_r(a)\setminus\{a\}=\{x\in M:0<d(x,a)<r\}.$$

A subset $N\subseteq M$ is called a *neighborhood* of $a$ if there exists $r>0$ such that

$$B_r(a)\subseteq N.$$

<br>

**Definition 2.2.5.** Let $(M,d)$ be a metric space and let $A\subseteq M$ be given. The *interior* of $A$ is the set $\operatorname {int} A$ defined by 

$$\operatorname{int} A = \lbrace x\in M : \exists r>0 \ \left(B_r(x)\subseteq A\right)\rbrace .$$

$a$ is called an *interior point* of $A$ if $a\in \operatorname {int} A.$<br>
&emsp; The *closure* of $A$ is the set $\overline A$ defined by 

$$ \overline A = \lbrace x\in M : \forall r>0\ \left(B_r(x)\cap A \ne \varnothing \right)\rbrace.$$

$a$ is called an *closure point* of $A$ if $a\in \overline A.$<br>
&emsp; $a$ is called a *limit point* of $A$ if $a\in A'$ where 

$$A' = \lbrace x\in M :  \forall r>0 \ \left(B_r^{\ast}(x)\cap A\neq\varnothing\right) \rbrace .$$ 

If $a\in A$ and $a\notin A'$ then $a$ is *isolated.*<br>
<br>

**Definition 2.2.6.** Let $(M,d)$ be a metric space. A set $A\subseteq M$ is *open* if every point of $A$ is an interior point.<br>
&emsp; A set $A\subseteq M$ is *closed* if it contains all of its limit points, equivalently if $A=\overline A$.<br>
&emsp; A set $A\subseteq M$ is *bounded* if 

$$ \exists r>0\ \exists x\in M\ (A\subseteq B_r(x)). $$
&emsp; A set $A\subseteq M$ is *dense* in $M$ if 

$$ \forall x\in M\ (x\in (A'\cup A)).$$

<br>

**Theorem 2.2.7.** Every neighborhood is open.<br>
