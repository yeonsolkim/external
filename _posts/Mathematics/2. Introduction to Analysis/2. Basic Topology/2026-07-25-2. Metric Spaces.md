**Definition 2.2.1.** Let $P$ and $R$ be a point sort and a scalar sort, respectively. Then, we let

$$\mathcal L_{\mathrm{met}} = \left\{ P,R,\, 0_R,+_R,<_{R},\, d \right\},$$

where $0_R$ is a constant of sort $R, +_R:R^2\to R, <_{R}\subseteq R^2,$ and $d:P^2\to R$ is a function symbol. An $\mathcal L_{\mathrm{met}}$-structure therefore has the form

$$\mathcal M = \left( M,S;\, 0^{\mathcal M},+^{\mathcal M},<^{\mathcal M},d^{\mathcal M} \right),$$

where $M$ is the set of points and $S$ is the set in which distances take their values. We henceforth suppose that the scalar sort is interpreted as the ordered additive structure of the real numbers. That is,

$$\mathcal M_{(M,d)} = (M,\mathbb R;\,0,+,<,d).$$

<br>

**Definition 2.2.2.** $\mathcal M_{(M,d)}$ is a *metric space* if it satisfies the following sentences, where $x,y,z$ range over the point sort $P\!:$

1. $\forall x,y\ (0\le d(x,y)),$
2. $\forall x,y\ (d(x,y)=0\leftrightarrow x=y),$
3. $\forall x,y\ (d(x,y)=d(y,x)),$
4. $\forall x,y,z\ \left(d(x,z)\le d(x,y)+d(y,z)\right).$
{:marker-prefix="M" }

In this case, $d$ is called the *metric* on $M.$<br>
<br>

**Definition 2.2.3.** A set $S\subseteq \mathbb R^k$ is *convex* if 

$$\forall x,y\in S\ \forall \lambda \in (0,1)\ \left( \lambda x + (1-\lambda)y\in S\right).$$

<br>

**Example 2.2.4.** Let $a_i<b_i$ for $i=1,\dots, k,$ and define $S$ to be the set of all points $x=(x_1,\dots,x_k)$ in $\mathbb R^k$ such that $x_i\in [a_i,b_i]$ for $i=1,\dots, k.$ The set $S$ is called a $k$-*cell*.<br>
&emsp; Let $x,y\in S, \lambda \in (0,1),$ and $z_i = \lambda x_i + (1-\lambda)y_i.$ Since 

$$ \lambda a_i\le \lambda x_i \le \lambda b_i\quad \text{and} \quad (1-\lambda)a_i\le (1-\lambda)y_i\le (1-\lambda)b_i,$$

we have $a_i\le z_i\le b_i,$ so that $z_i\in S.$ Thus $S$ is convex.<br>
&emsp; In general, $k$-cells are convex.<br>
<br>

**Definition 2.2.5.** Let $(M,d)$ be a metric space. For $a\in M$ and $r\in\mathbb R_{>0}$, the *open ball* of radius $r$ centered at $a$ is defined externally by

$$B_r(a)=\{x\in M:d(x,a)<r\}.$$

The corresponding *closed ball* and *punctured open ball* are

$$\overline B_r(a)=\{x\in M:d(x,a)\le r\}$$

and

$$B_r^{\ast}(a)=B_r(a)\setminus\{a\}=\{x\in M:0<d(x,a)<r\}.$$

<br>

**Definition 2.2.6.** Let $(M,d)$ be a metric space. A subset $N\subseteq M$ is a *neighborhood* of $a\in M$ if 

$$\exists r>0\ \left( B_r(a)\subseteq N\right) .$$

<br>

**Definition 2.2.7.** Let $(M,d)$ be a metric space, and let $A\subseteq M.$ The *interior* of $A$ is the set $\operatorname {int} A$ defined by 

$$\operatorname{int} A = \lbrace x\in M : \exists r>0 \ \left(B_r(x)\subseteq A\right)\rbrace .$$

$a\in M$ is an *interior point* of $A$ if $a\in \operatorname {int} A.$ $A$ is *open* if $A\subseteq \operatorname {int}A.$<br>
<br>

**Theorem 2.2.8.** Every open ball is open.<br><br>
*Proof.* Let $(M,d)$ be a metric space. Then let $a\in M$ and $r>0$ be arbitrary, and let $A=B_r(a).$ We show that $x\in A$ implies $x\in \operatorname {int} A.$ If $x\in A$ then $d(x,a)<r.$ We choose $s>0$ so that $s<r-d(x,a).$ Since, for any $y\in M,$ 

$$ d(y,x)<s \quad \Longrightarrow \quad d(y,a)\le d(y,x)+d(x,a)<s+d(x,a)<r,$$ 

we have $B_s(x)\subseteq A.$ Hence $x\in \operatorname {int} A.$ Therefore it is concluded that $A\subseteq \operatorname {int} A$ and $A$ is open. <span class="qed">$\square$</span><br>
<br>

**Definition 2.2.9.** Let $(M,d)$ be a metric space, and let $A\subseteq M.$ We define the set $A'$ whose elements are called the *limit points* of $A$ by

$$A' = \lbrace x\in M :  \forall r>0 \ \left(B_r^{\ast}(x)\cap A\neq\varnothing\right) \rbrace .$$  

If $a\in A$ is not a limit point of $A,$ then $a$ is an *isolated point* of $A.$ The set $A$ is _closed_ if $A'\subseteq A,$ and is _perfect_ if $A$ is closed and has no isolated points.<br>
<br>

**Definition 2.2.10.** Let $(M,d)$ be a metric space, and let $A\subseteq M.$ $A$ is *bounded* if 

$$ \exists r>0\ \exists x\in M\ \left( A\subseteq B_r(x)\right) .$$

<br>


**Example 2.2.11.** Let $A=\lbrace 1/n : n\in \mathbb N_{>0}\rbrace \subseteq \mathbb R.$ Its interior relative to $\mathbb R$ is empty. Indeed, fix $a=1/n\in A,$ and let $r>0.$ Choose an irrational number $t$ with $0<|t|<r.$ Then $a+t\in B_r(a)$ but $a+t\notin A.$ Thus no point of $A$ is an interior point. Hence $a\in \operatorname {int} A$ means more than merely $a\in A.$ It means that membership in $A$ persists for all points sufficiently close to $a.$<br>
&emsp; The point $0$ is a limit point of $A.$ Indeed, for every $r>0,$ Theorem 1.1.9 gives $n\in \mathbb N_{>0}$ such that $1<nr.$ Consequently, 

$$ \frac 1 n \in B_r^{\ast}(0)\cap A,$$ 

so $0\in A'.$ On the other hand, each $1/n$ is isolated in $A.$ Moreover, any $x\notin A\cup \lbrace 0\rbrace$ has a sufficiently small ball disjoint from $A.$ Hence $A' = \lbrace 0\rbrace.$ <br>
<br>

**Example 2.2.12.** Let $\mathbb C$ with its usual metric $d(x,y) = |x-y|$ be a metric space, and let $A = \lbrace x\in \mathbb C : |x|<1\rbrace.$ Then the point $(1,0)$ is a limit point of $A,$ while $(1,0)\notin A.$ Thus $A$ does not contain all of its limit points, so $A$ is not closed. Since being closed is a necessary condition to be perfect, $A$ is also not perfect.<br>
On the other hand, $A$ is open. Indeed, if $x\in A$ then, for some $r>0,$ $B_r(x)\subseteq A.$ It follows that $x\in \operatorname {int} A.$ Thus $A\subseteq \operatorname {int} A,$ so that $A$ is open. Furthermore, since $A\subseteq B_1(0),$ $A$ is bounded.<br>
<br>

**Theorem 2.2.13.** Let $(M,d)$ be a metric space, and let $A\subseteq M$. If $a\in A'$, then, for every $r>0$, the set $B_r(a)\cap A$ is infinite.<br><br>
*Proof.* Suppose, for contradiction, that there exists $r>0$ such that $B_r(a)\cap A$ is finite. Then $B_r^{\ast}(a)\cap A$ is also finite. Since $a\in A'$, this set is nonempty. Thus, for some $n\in\mathbb N$, we may write

$$  
B_r^{\ast}(a)\cap A=\lbrace p_1,\ldots,p_n\rbrace .  
$$

Define

$$  
s=\min_{1\leq i\leq n} d(a,p_i).  
$$

Since $p_i\neq a$ for every $i$, we have $d(a,p_i)>0$, and hence $s>0$. Moreover, since every $p_i\in B_r(a)$, we have $s<r$.<br>
&emsp; We now claim that $B_s^{\ast}(a)\cap A=\varnothing.$ Indeed, if $x\in B_s^{\ast}(a)\cap A$ then we have $x\in B_r^{\ast}(a)\cap A,$ since $s<r.$ Thus $x=p_i$ for some $i,$ and

$$  
s \le d(a,p_i) = d(a,x),
$$

which contradicts $x\in B^{\ast}_s(a).$ Therefore $B_s^{\ast}(a)\cap A=\varnothing$, contradicting $a\in A'$. Hence it is concluded that $B_r(a)\cap A$ is infinite for every $r>0$. <span class="qed">$\square$</span><br>
<br>

**Theorem 2.2.14.** Let $(M,d)$ be a metric space. A set $A\subseteq M$ is open if and only if $A^c$ is closed.<br><br>
*Proof.* Suppose that $A^c$ is closed and let $x\in A.$ Then $x\notin \left(A^c\right)'.$ Hence we can choose $r>0$ so that $B^{\ast}_r(x)\cap A^c=\varnothing.$ It follows that $y\in B_r(x)$ implies $y\notin A^c$ so that $y\in A.$ Therefore $B_r(x)\subseteq A,$ and thus $A\subseteq \operatorname {int} A,$ which implies $A = \operatorname {int} A.$ Hence $A$ is open.<br>
&emsp; Conversely, suppose that $A$ is open and $x\in A.$ Then we can choose $r>0$ so that $B_r(x)\subseteq A.$ We claim that $B^{\ast}_r(x)\cap A^c = \varnothing.$ Indeed, if there exists $y\in B^{\ast}_r(x)\cap A^c,$ then $y\in B_r(x)$ and $y\notin A,$ which contradicts $B_r(x)\subseteq A.$ Thus $B^{\ast}_r(x)\cap A^c = \varnothing,$ so $x$ is not a limit point of $A^c.$ Hence every limit point of $A^c$ is a member of $A^c.$ Therefore $A^c$ is closed.<span class="qed">$\square$</span><br>
<br>

**Theorem 2.2.15.** Let $(M,d)$ be a metric space, and let $A_i\subseteq M$ for every $i\in I.$ 
1. If $A_i$ is open for every $i\in I,$ then $\bigcup_{i\in I } A_i$ is open.
2. If $A_i$ is closed for every $i\in I,$ then $\bigcap_{i\in I } A_i$ is closed.

*Proof.* (1) Suppose that $x\in \bigcup_{i\in I } A_i.$ Then we may let $x\in A_i$ for some $i\in I.$ Since $A_i$ is open, there exists $r>0$ such that $B_r(x)\subseteq A_i.$ Since $A_i\subseteq \bigcup_{i\in I } A_i,$ we have $B_r(x)\subseteq \bigcup_{i\in I } A_i.$ Therefore $\bigcup_{i\in I } A_i$ is open.<br>
&emsp; (2) By Theorem 2.2.14, $A_i^c$ is open for every $i\in I.$ Then $\bigcup_{i\in I } A^c_i$ is open by (1). Since 

$$\bigcup_{i\in I } A^c_i = \lowparen{\bigcap_{i\in I } A_i}^{\!\!c},$$

$\bigcap_{i\in I } A_i$ is closed by Theorem 2.2.14.<span class="qed">$\square$</span><br>
<br>

**Theorem 2.2.16.** Let $(M,d)$ be a metric space, and let $A_i\subseteq M$ for every $i\in I$ where $I$ is a finite set. 
1. If $A_i$ is open for every $i\in I,$ then $\bigcap_{i\in I } A_i$ is open.
2. If $A_i$ is closed for every $i\in I,$ then $\bigcup_{i\in I } A_i$ is closed.

*Proof.* (1) Suppose that $x\in \bigcap_{i\in I } A_i.$ Then, for every $i\in I,$ we have $x\in A_i.$ Since $A_i$ is open, there exists $r_i>0$ such that $B_{r_i}(x)\subseteq A_i.$ We let 

$$ r = \min_{i\in I}r_i.$$

Then $B_r(x)\subseteq A_i$ for every $i\in I,$ so that $B_r(x)\subseteq \bigcap_{i\in I } A_i.$ Hence $\bigcap_{i\in I } A_i$ is open.<br>
&emsp; (2) By Theorem 2.2.14, $A_i^c$ is open for every $i\in I.$ Then $\bigcap_{i\in I } A^c_i$ is open by (1). Since 

$$\bigcap_{i\in I } A^c_i = \lowparen{\bigcup_{i\in I } A_i}^{\!\!c},$$

$\bigcup_{i\in I } A_i$ is closed by Theorem 2.2.14.<span class="qed">$\square$</span><br>
<br>

**Remark 2.2.17.** The necessity of $I$'s being finite in the preceding theorem can be illustrated by the following example. For $n\in \mathbb N_{>0},$ we let 

$$ A_n = \left( -\frac 1 n, \frac 1 n\right).$$

Then $A_n$ is open in $\mathbb R.$ However $\bigcap_{n\in \mathbb N_{>0}}A_n$ consists of a single point, namely, $x=0,$ and is therefore not open in $\mathbb R.$ Similarly, the union of an infinite set of closed sets need not be closed.<br>
<br>

**Definition 2.2.18** Let $(M,d)$ be a metric space, and let $A\subseteq M.$ The *closure* of $A$ is the set $\overline A$ defined by 

$$ \overline A = A\cup A'.$$

$a\in M$ is a *closure point* of $A$ if $a\in \overline A.$ The set $A$ is _dense_ in $M$ if $M\subseteq \overline A.$ <br>
<br>

**Proposition 2.2.19.** Let $(M,d)$ be a metric space, and let $A\subseteq M,$ then
1. $\overline A$ is closed,
2. $A = \overline A$ if and only if $A$ is closed,
3. $\overline A \subseteq X$ for every closed set $X\subseteq M$ such that $A\subseteq X.$

*Proof.*<br>
