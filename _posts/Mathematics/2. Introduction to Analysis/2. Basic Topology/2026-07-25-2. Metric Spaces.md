**Definition 2.2.1.** Let $P$ and $R$ be a point sort and a scalar sort, respectively. Then, we let

$$\mathcal L_{\mathrm{met}} = \left\{ P,R,\, 0_R,+_R,<_{R},\, d \right\},$$

where $0_R$ is a constant of sort $R, +_R:R^2\to R, <_{R}\subseteq R^2,$ and $d:P^2\to R$ is a function symbol. An $\mathcal L_{\mathrm{met}}$-structure therefore has the form

$$\mathcal M = \left( M,S;\, 0^{\mathcal M},+^{\mathcal M},<^{\mathcal M},d^{\mathcal M} \right),$$

where $M$ is the set of points and $S$ is the set in which distances take their values.<br>
&emsp; Suppose that the scalar sort is interpreted as the ordered additive structure of the real numbers. That is,

$$\mathcal M_{(M,d)} = (M,\mathbb R;\,0,+,<,d).$$

$\mathcal M_{(M,d)}$ is a *metric space* if it satisfies the following sentences, where $x,y,z$ range over the point sort $P\!:$

1. $\forall x,y\ (0\le d(x,y)),$
2. $\forall x,y\ (d(x,y)=0\leftrightarrow x=y),$
3. $\forall x,y\ (d(x,y)=d(y,x)),$
4. $\forall x,y,z\ \left(d(x,z)\le d(x,y)+d(y,z)\right).$
{:marker-prefix="M" }

In this case, $d$ is called the *metric* on $M.$<br>
<br>

**Definition 2.2.2.** A set $S\subseteq \mathbb R^k$ is *convex* if 

$$\forall x,y\in S\ \forall \lambda \in (0,1)\ \left( \lambda x + (1-\lambda)y\in S\right).$$

<br>

**Example 2.2.3.** Let $a_i<b_i$ for $i=1,\dots, k,$ and define $S$ to be the set of all points $x=(x_1,\dots,x_k)$ in $\mathbb R^k$ such that $x_i\in [a_i,b_i]$ for $i=1,\dots, k.$ The set $S$ is called a $k$-*cell*.<br>
&emsp; Let $x,y\in S, \lambda \in (0,1),$ and $z_i = \lambda x_i + (1-\lambda)y_i.$ Since 

$$ \lambda a_i\le \lambda x_i \le \lambda b_i\quad \text{and} \quad (1-\lambda)a_i\le (1-\lambda)y_i\le (1-\lambda)b_i,$$

we have $a_i\le z_i\le b_i,$ so that $z_i\in S.$ Thus $S$ is convex.<br>
&emsp; In general, $k$-cells are convex.<br>
<br>

**Definition 2.2.4.** Let $(M,d)$ be a metric space. For $a\in M$ and $r\in\mathbb R_{>0}$, the *open ball* of radius $r$ centered at $a$ is defined externally by

$$B_r(a)=\{x\in M:d(x,a)<r\}.$$

The corresponding *closed ball* and *punctured open ball* are

$$\overline B_r(a)=\{x\in M:d(x,a)\le r\}$$

and

$$B_r^{\ast}(a)=B_r(a)\setminus\{a\}=\{x\in M:0<d(x,a)<r\}.$$

<br>

**Example 2.2.5.** Let $(M,d)$ be a metric space where 

$$
d(x,y)=
\begin{cases}
0,&x=y,\\
1,&x\ne y.
\end{cases}
$$

For $a\in M,$ if $0<r\le 1$ then $B_r(a)=\lbrace a\rbrace,$ and if $1<r$ then $B_r(a) = M.$<br>
<br>

**Definition 2.2.6.** Let $(M,d)$ be a metric space. A subset $N\subseteq M$ is a *neighborhood* of $a\in M$ if 

$$\exists r>0\ \left( B_r(a)\subseteq N\right) .$$

<br>

**Definition 2.2.7.** Let $(M,d)$ be a metric space, and let $A\subseteq M.$<br>
&emsp; The *interior* of $A$ is the set $\operatorname {int} A$ defined by 

$$\operatorname{int} A = \lbrace x\in M : \exists r>0 \ \left(B_r(x)\subseteq A\right)\rbrace .$$

$a\in M$ is an *interior point* of $A$ if $a\in \operatorname {int} A.$<br>
&emsp; The *closure* of $A$ is the set $\overline A$ defined by 

$$ \overline A = \lbrace x\in M : \forall r>0\ \left(B_r(x)\cap A \ne \varnothing \right)\rbrace.$$

$a\in M$ is a *closure point* of $A$ if $a\in \overline A.$<br>
&emsp; Let

$$A' = \lbrace x\in M :  \forall r>0 \ \left(B_r^{\ast}(x)\cap A\neq\varnothing\right) \rbrace .$$  

$a\in M$ is a *limit point* of $A$ if $a\in A'.$ If $a\in A$ and $a\notin A'$ then $a$ is an *isolated* point of $A.$<br>
<br>

**Definition 2.2.8.** Let $(M,d)$ be a metric space, and let $A\subseteq M.$ <br>
&emsp; The set $A$ is *open* if 

$$A=\operatorname {int}A,$$

$A$ is _closed_ if 

$$A=\overline A,$$ 

$A$ is _perfect_ if 

$$A=A',$$

and $A$ is _dense_ in $M$ if 

$$\overline A=M.$$

The set $A$ is _bounded_ if

$$  
\exists x\in M\ \exists r>0\ (A\subseteq B_r(x)).  
$$

<br>

**Theorem 2.2.9.** Every open ball is open.<br><br>
*Proof.* Let $(M,d)$ be a metric space. Also let $a\in M$ and $r>0$ be arbitrary, and $A=B_r(a).$ We show that $x\in A$ implies $x\in \operatorname {int} A.$ If $x\in A$ then $d(x,a)<r.$ We choose $s>0$ so that $s<r-d(x,a).$ Since, for any $y\in M,$ 

$$ d(y,x)<s \quad \Longrightarrow \quad d(y,a)\le d(y,x)+d(x,a)<s+d(x,a)<r,$$ 

we have $B_s(x)\subseteq A.$ Hence $x\in \operatorname {int} A.$ Therefore it is concluded that $A\subseteq \operatorname {int} A$ and $A$ is open. <span class="qed">$\square$</span><br>
<br>

**Theorem 2.2.10.** Let $(M,d)$ be a metric space, and let $A\subseteq M.$ If $a\in A',$ then, for all $r>0,$ $A\cap B_r(a)$ is infinite.<br><br>
*Proof.* Let $A\subseteq M$ and $a\in A'.$ Suppose, for contradiction, that there exists $r>0$ such that $A\cap B_r(a)$ is finite. Let $p_1,\dots, p_n$ be the points of $A\cap B_r(a),$ which are distinct from $a.$<br>
&emsp; We consider an open ball $B_s(a)$ where 

$$ s = \min_{1\le m\le n}d(a,p_n).$$ 

Since $B_s(a)$ contains no point $q$ of $A$ such that $q\ne a,$ we have $a\notin A',$ which contradicts the fact that $a\in A'.$ Hence, it is concluded that Theorem 2.2.10 is in fact true. <span class="qed">$\square$</span><br>
