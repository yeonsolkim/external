**Definition 1.2.1.** A *probability space* consists of a sample space $\Omega$ and a *probability function* which takes an event as input and returns a real number between $0$ and $1$ as output satisfying the following axioms: 
1. $P(\varnothing) = 0$ and $P(\Omega) = 1$;
2. if $\{A_i\}_{i\in I}$ is a collection of mutually exclusive events, then 
   
   $$ P\lowparen{\bigcup_{i\in I}A_i} = \sum_{i\in I} P(A_i).$$
{:marker-prefix="PS" }

**Example 1.2.2.** When all outcomes in a finite sample space are equally likely, the probability of an event may be defined to be the number of outcomes it contains divided by the total number of outcomes. We now check whether this definition satisfies the probability space axioms.
Let $\Omega$ be finite. Then we define a function $P$ by

$$ P(A) = \frac{|A|}{|\Omega|}$$ 

for all $A\subseteq \Omega$. Then $P(\varnothing) = 0$ and $P(\Omega) = 1$. Furthermore, if $A_1,\ldots,A_n\subseteq \Omega$, then we have 

$$ 
\begin{aligned}
P(A_1\cup \cdots \cup A_n) 
&= \frac{|A_1\cup \cdots \cup A_n|}{|\Omega|} \\
&= \frac{|A_1| + \cdots + |A_n|}{|\Omega|} \\
&= \frac{|A_1|}{|\Omega|} + \cdots + \frac{|A_n|}{|\Omega|}= \sum_{i=1}^n P(A_i).
\end{aligned}
$$

That is, (PS1) and (PS2) hold; hence $(\Omega, P)$ is a probability space.

**Proposition 1.2.3.** If $(\Omega,P)$ is a probability space and $A,B\subseteq \Omega$ then 
1. $P(A^c) = 1 -P(A)$;
2. if $A\subseteq B$, then $P(A)\le P(B)$;
3. $P(A\cup B) = P(A) + P(B) - P(A\cap B)$.
