**Definition 4.1.1.** A *universe* $\mathcal U$ is a set satisfying the following properties: 
1. $\varnothing \in \mathcal U,$
2. $\forall x\ (x\in \mathcal U \rightarrow x \subseteq \mathcal U),$
3. $\forall x\ (x\in \mathcal U \rightarrow \lbrace x\rbrace \in \mathcal U),$
4. $\forall x\ (x\in \mathcal U \rightarrow \mathcal P(x)\in \mathcal U),$
5. $\forall I\in \mathcal U\ \forall i\in I\ \left( x_i\in \mathcal U \rightarrow \bigcup_{i\in I}x_i\in \mathcal U\right),$
6. $\mathbb N\in \mathcal U.$

<br>

**Axiom 4.1.2** (Axiom of universes). We add an axiom to the $\text{ZF}$ theory: For all $x,$ there exists a universe $\mathcal U$ such that $x\in \mathcal U.$<br>
<br>

**Definition 4.1.3.** Let $\mathcal U$ be a universe.
1. A set $x$ is a $\mathcal U$-*set* if $x\in \mathcal U.$
2. A set $x$ is a $\mathcal U$-*small* if it is isomorphic to a set $y\in \mathcal U.$

<br>

**Definition 4.1.4.** A *category* $\mathscr C$ consists of: 
1. a set $\operatorname {Ob}(\mathscr C),$
2. for any $X,Y\in \operatorname {Ob}(\mathscr C),$ a set $\operatorname {Hom}_{\mathscr C}(X,Y).$
3. for any $X,Y,Z\in \operatorname {Ob}(\mathscr C),$ a map 
   
   $$ \operatorname {Hom}_{\mathscr C}(X,Y) \times \operatorname {Hom}_{\mathscr C}(Y,Z) \to \operatorname {Hom}_{\mathscr C}(X,Z)$$
   
   called the *composition* and denoted by $(f,g)\mapsto g\circ f,$ satisfying the following properties: 
   - (associativity) $\forall f\in \operatorname {Hom}_{\mathscr C}(X,Y)\ g\in \operatorname {Hom}_{\mathscr C}(Y,Z)\ h\in \operatorname {Hom}_{\mathscr C}(Z,W)$ $\left((h\circ g)\circ f)=h\circ (g\circ f)\right),$
   - (identity) $\forall X\in \operatorname {Ob}(\mathscr C)\ \exists \text{id}_X\in \operatorname {Hom}_{\mathscr C}(X,X)\ \forall f\in \operatorname {Hom}_{\mathscr C}(X,Y)\ \forall g\in \operatorname {Hom}_{\mathscr C}(Y,X)$ $\left(\left(f\circ \text{id}_X = f\right) \land \left( \text{id}_X \circ g = g\right)\right).$

<br>

**Definition 4.1.5.** Let $\mathscr C$ be a category. An element of $\operatorname {Ob}(\mathscr C)$ is an *object* of $\mathscr C.$ For $X,Y\in \operatorname {Ob}(\mathscr C),$ an element of $\operatorname {Hom}_{\mathscr C}(X,Y)$ is a *morphism* in $\mathscr C.$ The morphism $\text{id}_X$ is the *identity* of $X.$<br>
&emsp;$\mathscr C$ is a $\mathcal U$-*category* if $\operatorname {Hom}_{\mathscr C}(X,Y)$ is $\mathcal U$-small for any $X,Y\in \operatorname {Ob}(\mathscr C).$<br>
&emsp;$\mathscr C$ is a $\mathcal U$-*small category* if $\mathscr C$ is a $\mathcal U$-category and $\operatorname {Ob}(\mathscr C)$ is $\mathcal U$-small.<br>
