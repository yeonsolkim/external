**Definition 1.4.1.** A relation $\le$ on a set $P$ is called a *partial order* on $P$ if the following hold:
1. $\forall x\in P\ (x\le x)$ (*reflexivity*);
2. $\forall x,y\in P\ ((x\le y\land y\le x)\rightarrow x=y)$ (*antisymmetry*);
3. $\forall x,y,z\in P\ ((x\le y \land y\le z) \rightarrow x\le z)$ (*transitivity*).

The set $P$ equipped with the partial order is called a *partially ordered set* or *poset*.

In the setting of posets, two elements may *not* be related to each other at all. 
An element $x$ of a poset $P$ is related to itself by the order relation. In other words, $x$ both precedes and follows itself. Two elements of $P$ can precede and follow each other in this way only when they are the same element. This is what the first two axioms express. 
The third axiom says that whenever two order relations are linked by a common intermediate element, the two elements at the ends are also related by the order relation. 

**Definition 1.4.2.** Let $P$ and $Q$ be two posets with order relations $\le_P$ and $\le_Q$ respectively. A function $f\colon P\to Q$ is called a *monotone map* or *order-preserving map* if 

$$ x\le_P y \implies f(x)\le_Q f(y)$$

for all $x\in P$ and $y\in Q$. 

**Definition 1.4.2.** Let $P$ and $Q$ be two posets with order relations $\le_P$ and $\le_Q$ respectively. The posets $P$ and $Q$ are said to have the same *order type* if there exists a bijective function $f\colon P\to Q$ such that

$$ x\le_P y \iff f(x)\le_Q f(y)$$

for all $x\in P$ and $y\in Q$. In this case, the function $f$ is called an *order-isomorphism*.

**Definition 1.4.3.** A partial order $\le$ on a set $T$ is said to be a *total order* on $T$ if

 $$\forall x,y\in T\ (x\le y\lor y\le x).$$

The set $T$ equipped with the total order is called a *totally ordered set* or *toset*.

**Proposition 1.4.4.** Every toset of $n$ elements has the same order type as $\{1,\ldots,n\}$. 

*Proof.* Let $T$ be a toset of $n$ elements, and define 

$$ f\colon T\to \{1,\ldots,n\},\qquad f(x) = |\{y\in T : y\le x\}|.$$

Suppose $x_1,x_2\in T$ and $x_1 < x_2$. By transitivity, we have 

$$\begin{align}
\{y\in T : y\le x_1\} &\subset \{y\in T : y\le x_1\}\cup \{x_2\}\\
&\subseteq \{y\in T : y\le x_2\}.
\end{align}$$

Hence $f(x_1)<f(x_2)$, which implies that $f$ is monotone and injective. We also have $|\operatorname{im}f| = n$, so $f$ is a bijection. Now suppose $x_1,x_2\in T$ and $f(x_1)\le f(x_2)$. If $x_2$ was less than $x_1$, 

$$ 
\begin{align}
\{y\in T : y\le x_2\} &\subset \{y\in T : y\le x_2\}\cup \{x_1\} \\
&\subseteq \{y\in T : y\le x_1\},
\end{align}
$$

so that $f(x_2)<f(x_1)$. Hence $x_1\le x_2$. Consequently, $f$ is an order-isomorphism.<span class="qed">$\square$</span>


**Definition 1.4.5.** Let $P$ be a poset and let $a,b\in P$.
1. If $a\le x$ for all $x\in P$, then $a$ is called a *least element*.
2. If $x\le a$ implies $x=a$ for all $x\in P$, then $a$ is called a *minimal element*.
3. If $x\le b$ for all $x\in P$, then $b$ is called a *greatest element*.
4. If $b\le x$ implies $x=b$ for all $x\in P$, then $b$ is called a *maximal element*.


**Theorem 1.4.6.** 
1. If there exists a least element of a poset then it is minimal and unique.
2. Any minimal element of a toset is the least element.

*Proof.* (1) Let $a$ be a least element of a poset $P$. If $x\le a,$ then $x=a,$ since $\le$ is antisymmetric. Hence $a$ is minimal.
Suppose that $b\in P$ is a least element. Then we have $a\le b$ and $b\le a,$ so $a=b.$ Hence such $a$ is unique.
(2) Let $a$ be a minimal element of a toset $T$. If $x\le a$ then $x=a$, so that $a\le x$. Hence we have $a\le x$ for all $x\in T$ by totality.<span class="qed">$\square$</span>


**Definition 1.4.7.** Let $P$ be a poset, and $S\subseteq P$. If there is an element $a\in P$ such that $a\leq x$ for all $x\in S,$ $S$ is *bounded below* and $a$ is a *lower bound* for $S.$ If $a\in S,$ then $a$ is the least element of $S.$
Similarly, if there is an element $b\in P$ such that $x\leq b$ for all $x\in S,$ $S$ is *bounded above* and $b$ is an *upper bound* for $S.$ If $b\in S,$ then $b$ is the greatest element of $S$.

**Definition 1.4.8.** Let $P$ be a poset and $S\subseteq P$. Suppose that $S$ is bounded below and $\alpha$ is a lower bound for $S$. If $a\le \alpha$ for every lower bound $a$ for $S$, then $\alpha$ is called the *greatest lower bound* or the *infimum* for $S$. In this case we write

$$ \alpha = \inf {S}.$$


Now suppose that $S$ is bounded above and $\beta$ is an upper bound for $S$. If $\beta\le b$ for every upper bound $b$ for $S,$ then $\beta$  is called the *least upper bound* or the *supremum* for $S.$ In this case we write

$$ \beta = \sup {S}.$$

**Definition 1.4.9.** A poset $P$ is said to have the *greatest-lower-bound property* if, for every nonempty subset $S$ that is bounded below, there exists $\alpha\in P$ such that $\alpha = \inf {S}.$
Similarly, a poset $P$ is said to have the *least-upper-bound property* if, for every nonempty subset $S$ that is bounded above, there exists $\beta\in P$ such that $\beta = \sup {S}.$

**Proposition 1.4.10.** Suppose that $P$ is a poset with the least-upper-bound property, $S$ is a nonempty subset of $P,$ and $S$ is bounded below. Let $T$ be the set of all lower bounds for $S.$ Then there exists $\alpha\in P$ such that

$$\alpha = \inf S\quad \text{and} \quad \alpha = \sup T.$$

*Proof.* Since $S$ is bounded below, $T$ is not empty. Since every $x\in S$ is an upper bound for $T,$ $T$ is bounded above. Given that $P$ has the least-upper-bound property, there exists $\alpha\in P$ such that $\alpha=\sup T.$
Since every $x\in S$ is an upper bound for $T$ and $\alpha$ is the least upper bound for $T,$ $\alpha$ is a lower bound for $S.$
Let $y$ be any lower bound of $S.$ By the definition of $T,$ $y\in T.$ Since $\alpha=\sup T,$ $y\le \alpha.$ Consequently, $\alpha$ is the greatest lower bound for $S.$ <span class="qed">$\square$</span>

Given two related elements of a poset, the set of all elements that follow the earlier element and precede the later element at the same time is called an interval.

**Definition 1.4.11.** Let $P$ be a nonempty poset. For $x,y\in P$ with $x\leq y$, the *interval* from $x$ to $y$ is the set

$$ [x,y]=\{z\in P:x\leq z\leq y\}. $$

An interval is regarded as a poset under the order inherited from $P$.
