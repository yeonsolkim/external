**Definition 1.4.1.** A relation $\le$ on a set $A$ is called a *partial order* on $A$ if the following hold:
1. $\forall x\in A\ (x\le x)$ (*reflexivity*);
2. $\forall x,y\in A\ ((x\le y\land y\le x)\rightarrow x=y)$ (*antisymmetry*);
3. $\forall x,y,z\in A\ ((x\le y \land y\le z) \rightarrow x\le z)$ (*transitivity*).

A set equipped with a partial order is called a *partially ordered set* or *poset*.


**Definition 1.4.2.** A partial order $\le$ on a set $A$ is said to be a *total order* on $A$ if it has *comparability*:

 $$\forall x,y\in A\ ((x\le y)\lor (y\le x)).$$

A set equipped with a total order is called a *totally ordered set* or *toset*.

**Definition 1.4.3.** Let $A$ be a poset. An element $a$ of $A$ is a *least element* of $A$ if

$$ \forall x\in A\ (a\le x).$$

An element $a\in A$ is a *minimal element* of $A$ if

$$ \forall x\in A\ (x\le a \rightarrow x=a).$$



So, "least" means smaller than everything else, while "minimal" means nothing else is smaller.

**Proposition 1.4.4.** Let $A$ be a poset.
1. If there exists a least element of $A,$ then it is minimal and it is unique.
2. If $\le$ is a total order, then any minimal element is the least element.

*Proof.* (1) Let $a$ be a least element if $A.$ If $x\le a,$ then $x=a,$ since $\le$ is antisymmetric. Hence $a$ is minimal.
Suppose that $a'\in A$ is a least element. Then we have $a\le a'$ and $a'\le a,$ so $a=a'.$ Hence such $a$ is unique.
(2) Let $a$ be a minimal element. If $x\le a$ then $x=a$, so that $a\le x$. Hence we have $a\le x$ for all $x\in A$ by totality.<span class="qed">$\square$</span>

**Definition 1.4.5.** An element $a$ of a poset $A$ is a *greatest element* of $A$ if 

$$ \forall x\in A\ (x\le a),$$

and $a$ is a *maximal element* of $A$ if 

$$ \forall x\in A\ (a\le x \rightarrow x=a).$$


**Definition 1.4.6.** Let $A$ and $B$ be two sets with order relations $\le_A$ and $\le_B$ respectively. The sets $A$ and $B$ have the same *order type* if there exists a bijective function $f\colon A\to B$ such that

$$ a_1\le_Aa_2 \iff f(a_1)\le_B f(a_2).$$

**Definition 1.4.7.** Let $A$ be a poset, and $A_0\subseteq A.$ If there is an element $a\in A$ such that $x\leq a$ for all $x\in A_0,$ $A_0$ is *bounded above* and $a$ is an *upper bound* for $A_0.$ If $a\in A_0,$ then $a$ is the greatest element of $A_0.$
Similarly, if there is an element $a\in A$ such that $a\leq x$ for all $x\in A_0,$ $A_0$ is *bounded below* and $a$ is a *lower bound* for $A_0.$ If $a\in A_0,$ then $a$ is the least element of $A_0.$

**Definition 1.4.8.** Let $A$ be a poset and $A_0\subseteq A.$ Suppose that $A_0$ is bounded above and $a$ is an upper bound for $A_0.$ If $a\le a'$ for every upper bound $a'$ for $A_0,$ then $a$  is the *least upper bound* or the *supremum* for $A_0.$ In this case we write

$$ a = \sup {A_0}.$$

We now suppose that $A_0$ is bounded below and $a$ is a lower bound for $A_0.$ If $a'\le a$ for every lower bound $a'$ for $A_0,$ then $a$ is the *greatest lower bound* or the *infimum* for $A_0.$ In this case we write

$$ a = \inf {A_0}.$$

**Definition 1.4.9.** A poset $A$ has the *least-upper-bound property* if, for every nonempty subset $A_0$ that is bounded above, there exists $a\in A$ such that $a = \sup {A_0}.$
Similarly, $A$ has the *greatest-lower-bound property* if, for every nonempty subset $A_0$ that is bounded below, there exists $a\in A$ such that $a = \inf {A_0}.$

**Theorem 1.4.10.** Suppose that $A$ is a poset with the least-upper-bound property, $A_0$ is a nonempty subset of $A,$ and $A_0$ is bounded below. Let $L$ be the set of all lower bounds for $A_0.$ Then

$$ \exists a\in A \ (a = \sup L \ \land\ a = \inf A_0).$$

*Proof.* Since $A_0$ is bounded below, $L$ is not empty. Since every $y\in A_0$ is an upper bound for $L,$ $L$ is bounded above. Given that $A$ has the least-upper-bound property, there exists $a\in A$ such that $a=\sup L.$
Since every $y\in A_0$ is an upper bound for $L$ and $a$ is the least upper bound for $L,$ $a$ is a lower bound for $A_0.$
Let $x$ be any lower bound of $A_0.$ By the definition of $L,$ $x\in L.$ Since $a=\sup L,$ $x\le a.$ Consequently, $a$ is the greatest lower bound for $A_0.$ <span class="qed">$\square$</span>
