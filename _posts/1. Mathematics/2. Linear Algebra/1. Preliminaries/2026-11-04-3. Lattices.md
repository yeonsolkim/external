**Definition 1.3.1.** A *semilattice* is an ordered pair $(S,\vee)$ where $S$ is a set, $\vee$ is an associative, commutative, and idempotent binary operation on $S$. 

**Proposition 1.3.2.** Given a semilattice $(S,\vee)$, there is a unique partial order $\le$ on $S$ which makes $x\vee y$ the least upper bound for $\{x,y\}$ for all $x,y\in S$. 
Conversely, suppose that $S$ is a poset and any pair of two elements of $S$ has a least upper bound. If we write the least upper bound for $\{x,y\}$ as $x\vee y$, and regard $\vee$ as a binary operation on $S$, then $(S,\vee)$ is a semilattice.

**Definition 1.3.3.** A semilattice $(S,\vee)$ is called an *upper semilattice* if $x\vee y$ is interpreted as the least upper bound for $\{x,y\}$ for all $x,y\in S$. In this case, the operation $\vee$ is called *join*.
Replacing "least upper bound" with "greatest lower bound", we obtain the dual concept of a *lower semilattice*. To distinguish from the previous situation, we shall denote a lower semilattice by $(S,\wedge)$ and call $\wedge$ *meet*.

**Definition 1.3.4.** A *lattice* is an ordered pair $(L,\vee,\wedge)$ where $L$ is a set and $\vee$ and $\wedge$ are binary operations on $L$ satisfying the following: 
1. the ordered pair $(L,\vee)$ is an upper semilattice;
2. the ordered pair $(L,\wedge)$ is a lower semilattice;
3. we have for all $x,y\in L$
   
   $$ x\wedge(x\vee y) = x\quad \text{and} \quad x\vee(x\wedge y) = x.$$

**Proposition 1.3.5.** Given a set $S$, the ordered pair $(\mathcal{P}(S),\cup, \cap)$ is a lattice.
