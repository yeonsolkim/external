We suppose that $V$ and $W$ are vector spaces over the same field $F$, and $\tau$ is a function from $V$ to $W$. In this situation, $\tau$ is said to preserve addition if $\tau(u)=s$ and $\tau(v)=t$ implies $\tau(u+v)=s+t$ for all $u,v\in V$ and $s,t\in W$. Similarly, $\tau$ is said to preserve scalar multiplication if $\tau(v)=w$ implies $\tau(av)=aw$ for all $a\in F$, $v\in V$, and $w\in W$. If $\tau$ preserves both operations, then it is said to be *linear*. More generally, functions that preserve the operations defining an algebraic structure are called *homomorphisms*.

**Definition 3.1.1.** Let $V$ and $W$ be vector spaces over the same field $F$. A function $\tau\colon V\to W$ is called a *linear map* from $V$ to $W$ if for all $u,v\in V$ and $a\in F$ the following conditions hold: 
1. $\tau(u+v)=\tau(u) +\tau(v)$; 
2. $\tau(av) = a\tau(v)$.

The set of all linear maps from $V$ to $W$ is denoted by $\operatorname{Hom}(V,W)$. The *zero map* $0_{V,W}$ is a linear map from $V$ to $W$ such that $0_{V,W}(v)=0_W$ for all $v\in V$.
A linear map from $V$ to $V$ is called a *linear operator* on $V$. The *identity operator* $\operatorname{id}_V$ on $V$ is a linear operator on $V$ such that $\operatorname{id}_V(v)=v$ for all $v\in V$. The set of all linear operators on $V$ is denoted by $\operatorname{End}(V)$. A linear operator on a real vector space is called a *real operator*.

**Proposition 3.1.2.** Let $V$ and $W$ be vector spaces over $F$, and let $\tau\colon V \to W$ be a function.
1. If $\tau$ is linear, then $\tau(0_V)=0_W$.
2. If $\tau$ is linear, then $\tau(-v)=-\tau(v)$ for all $v\in V$.
3. The function $\tau$ is linear if and only if, for all $u,v\in V$ and $a\in F$, we have 
   
    $$\tau(au+v)=a\tau(u)+\tau(v).$$ 

*Proof.* (1) We have $v+0_V=v$ for all $v\in V$. Since $\tau$ is linear, $\tau(v) + \tau(0_V) = \tau(v)$. Since the zero vector in $W$ is unique, $\tau(0_V)=0_W$.
(2) Since $v+(-v)=0_V$, we have $\tau(v)+\tau(-v)=0_W$ by (1). Since the inverse of a vector is unique, $\tau(-v)=-\tau(v)$.
(3) If $\tau$ is linear, then $\tau(au+v)=\tau(au) + \tau(v)=a\tau(u) + \tau(v)$.
We now prove the converse. Setting $a=1$, we obtain $\tau(u+v)=\tau(u)+\tau(v)$. By (1), setting $v=0_V$ gives $\tau(au)=a\tau(u)$. Therefore $\tau$ is linear.<span class="qed">$\square$</span>

We first look at some examples of real operators.

**Example 3.1.3.** 
1. For any $\theta\in \mathbb R$, we define $\tau_{\theta}\colon \mathbb R^2\to \mathbb R^2$ by 
   
   $$ \tau_{\theta}(x,y) = (x\cos\theta - y\sin\theta, x\sin\theta + y\cos\theta).$$
   
   The operator $\tau_{\theta}$ is linear and is called the *rotation* by $\theta$.
1. The *reflection* about the $x$-axis defined by 
   
   $$ \tau\colon \mathbb R^2\to \mathbb R^2, \qquad \tau(x,y) = (x,-y)$$ 
   
   is linear.
1. The *projection* on the $x$-axis defined by 
   
   $$ \tau\colon \mathbb R^2\to \mathbb R^2,\qquad \tau(x,y)=(x,0)$$
   
   is linear.

In real analysis, differentiation and integration provide us with two of the most important examples of linear map.

**Example 3.1.4.** 
1. Let $C^{\infty}$ denote the set of all real-valued functions defined on $\mathbb R$ that have derivatives of every order. Then $C^{\infty}$ is a vector space. Define $D\colon C^{\infty}\to C^{\infty}$ by $Df=f'$. Then, for $f,g\in C^{\infty}$, 
   
   $$ D(af+g) = af'+g' = aDf + Dg.$$
   
   Hence $D$ is linear. The linear operator $D$ is called a *differential operator*.
1. Let $I$ be an interval, and define $\tau\colon C^1(I)\to \mathbb R$ by 
   
   $$ \tau(f) =\int_I f(x)\,dx.$$
   
   Then $\tau$ is a linear map.

**Theorem 3.1.5.** The set $\operatorname{Hom}(V,W)$ is a vector space under ordinary addition of functions and scalar multiplication of functions by elements of $F$.

*Proof.* Let $u,v\in V$ and $a,b\in F$. Since 

$$ \begin{align}
(\tau + \sigma)(au+v) &= \tau(au + v) + \sigma(au + v)\\
&= (a\tau(u) + \tau(v)) + (a\sigma(u) + \sigma(v))\\
&= a(\tau(u)+\sigma(u)) + (\tau(u) + \sigma(v))\\
&= a(\tau + \sigma)(u) + (\tau + \sigma)(v)
\end{align}
$$

and 

$$ \begin{align}
(a\tau)(bu + v) &= a\tau(bu + v)\\
&= a(b\tau(u) + \tau(v))\\
&= b(a\tau(u)) + a\tau(v)\\
&= b(a\tau)(u) + (a\tau)(v),
\end{align}
$$

the two operations are closed.
Associativity and commutativity of addition follow from those in $W$. The zero map is the additive identity and $-\tau\in \operatorname{Hom}(V,W)$ defined by $(-\tau)(v) = -\tau(v)$ for all $v\in V$ is the additive inverse of $\tau\in \operatorname{Hom}(V,W)$. Hence $\operatorname{Hom}(V,W)$ is an abelian group. Since scalar multiplication axioms follows from the corresponding axioms in $W$, $\operatorname{Hom}(V,W)$ is a vector space.<span class="qed">$\square$</span>

**Proposition 3.1.6.** If $\sigma \in \operatorname{Hom}(U,V)$ and $\tau\in \operatorname{Hom}(V,W)$, then the composition $\tau\sigma$ is in $\operatorname{Hom}(U,W)$.

**Theorem 3.1.7.** The vector space $\operatorname{End}(V)$ is a unital algebra, where multiplication is composition and $\operatorname{id}_V$ is the multiplicative identity.


**Theorem 3.1.8.** Let $B$ be a basis for $V$, and let $\tau, \sigma\in \operatorname{Hom}(V,W)$. If $\tau(b)=\sigma(b)$ for all $b\in B$, then $\tau=\sigma$.
