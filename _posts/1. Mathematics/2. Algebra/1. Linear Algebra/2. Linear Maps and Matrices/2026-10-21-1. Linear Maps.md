Informally speaking, a linear map is a map that *preserves* vector-space structure. In general, to say that something is preserved under a transformation means that it is retained despite the transformation. Thus, saying that a map $\tau\colon V\to W$ is linear means that the algebraic relations, including axioms, which define the vector-space structure of $V$ are preserved when its vectors are mapped into $W$. More precisely, the relations arising from vector addition and scalar multiplication continue to hold among their images in $W$.

**Definition 2.1.1.** Let $V$ and $W$ be vector spaces over the same field $F$. A function $\tau\colon V\to W$ is called a *linear map* from $V$ to $W$ if for all $u,v\in V$ and $a\in F$ the following conditions hold: 
1. $\tau(u+v)=\tau(u) +\tau(v)$; 
2. $\tau(av) = a\tau(v)$.

The set of all linear maps from $V$ to $W$ is denoted by $\operatorname{Hom}(V,W)$.
A linear map from $V$ to $V$ is called a *linear operator* on $V$. The set of all linear operators on $V$ is denoted by $\operatorname{End}(V)$. A linear operator on a real vector space is called a *real operator*.

**Proposition 2.1.2.** Let $V$ and $W$ be vector spaces over $F$, and let $\tau\colon V \to W$ be a function.
1. If $\tau$ is linear, then $\tau(0_V)=0_W$.
2. If $\tau$ is linear, then $\tau(-v)=-\tau(v)$ for all $v\in V$.
3. The function $\tau$ is linear if and only if $\tau(au+v)=a\tau(u)+\tau(v)$ for all $u,v\in V$ and $a\in F$.
4. The function $\tau$ is linear if and only if, for finite set $I$ and indexed families $\{v_i\}_{i\in I}$ in $V$ and $\{a_i\}_{i\in I}$ in $F$, we have
   
   $$ \tau\lowparen{\sum_{i\in I}a_iv_i} = \sum_{i\in I}a_i\tau(v_i).$$

*Proof.* (1) We have $v+0_V=v$ for all $v\in V$. Since $\tau$ is linear, $\tau(v) + \tau(0_V) = \tau(v)$. Since the zero vector in $W$ is unique, $\tau(0_V)=0_W$.
(2) Since $v+(-v)=0_V$, we have $\tau(v)+\tau(-v)=0_W$ by (1). Since the inverse of a vector is unique, $\tau(-v)=-\tau(v)$.

(4)<span class="qed">$\square$</span>

We first look at some examples of real operators.

**Example 2.1.3.** For any $\theta\in \mathbb R$, we define $\tau_{\theta}\colon \mathbb R^2\to \mathbb R^2$ by 

$$ \tau_{\theta}(x,y) = (x\cos\theta - y\sin\theta, x\sin\theta + y\cos\theta).$$

The operator $\tau_{\theta}$ is linear. Indeed, we have 

$$ \begin{align}
\tau_{\theta}(a(x,y)+(z,w))&= \tau_{\theta}(ax+z,ay+w) \\
&= ((ax+z)\cos\theta - (ay+w)\sin\theta, (ax+z)\sin\theta + (ay+w)\cos\theta)\\
&= a(x\cos\theta - y\sin\theta, x\sin\theta + y\cos\theta) + (z\cos\theta - w\sin\theta, z\sin\theta + w\cos\theta) \\
&= a\tau_{\theta}(x,y) + \tau_{\theta}(z,w).
\end{align}
$$

The real operator $\tau_{\theta}$ is called the *rotation* by $\theta$ in dimension $2$.


**Example 2.1.4.** We define $\tau\colon \mathbb R^2\to \mathbb R^2$ by $\tau(x,y) = (x,-y)$. Then $\tau$ is a real operator, and it is called the *reflection* about the $x$-axis, the set $\{(x,y)\in \mathbb R^2 : y=0\}$.

**Example 2.1.5.** We define $\tau\colon \mathbb R^2\to \mathbb R^2$ by $\tau(x,y)=(x,0)$. Then $\tau$ is a real operator, and it is called the *projection* on the $x$-axis.

In real analysis, differentiation and integration provide us with two of the most important examples of linear map.

**Example 2.1.6.** Let $C^{\infty}$ denote the set of all real-valued functions defined on $\mathbb R$ that have derivatives of every order. Then $C^{\infty}$ is a vector space. 
Define $D\colon C^{\infty}\to C^{\infty}$ by $Df=f'$. Then, for $f,g\in C^{\infty}$, 

$$ D(af+g) = af'+g' = aDf + Dg.$$

Hence $D$ is linear. The linear operator $D$ is called a *differential operator*.

**Example 2.1.7.** Let $I$ be an interval, and define $\tau\colon C^1\to \mathbb R$ by 

$$ f\longmapsto \int_I f(x)\,dx.$$

Then $\tau$ is a linear map.


A linear map need not be injective. In other words, it need not preserve distinctions between elements of its domain. Indeed, for a linear map $\tau\colon V\to W$, we have $\tau(u)=\tau(v)$ if and only if $\tau(u-v)=0_W$.
