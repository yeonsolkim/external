**Bases for a vector space.** The concepts of generating sets and linearly independent sets were introduced in the preceding two sections. We now seek a generating set for an entire vector space that contains no redundancy. This leads to the concept of a *basis* for a vector space.

**Definition 1.6.1.** Let $V$ be a vector space. A subset $S$ of $V$ is called a *basis* for $V$ if $\operatorname{span}(S)=V$ and $S$ is linearly independent.

**Example 1.6.2.** The empty set $\varnothing$ is a basis for the zero vector space, because $\operatorname{span}(\varnothing)=\{0_V\}$ and $\varnothing$ is linearly independent.

**Example 1.6.3.** In the vector space $F_n[x]$, the set $\{1,x,x^2,\ldots,x^n\}$ is a basis, called the *standard basis* for $F_n[x]$. While $F_n[x]$ has a finite basis, the infinite set $\{1,x,x^2,\ldots\}$ is a basis for $F[x]$.


The definition of a basis requires a set to have two properties at the same time: generating and linear independence. The next theorem shows that extremeizing only one of the two conditions motivating the definition is sufficient to characterize a basis. Here, minimality and maximality are understood with respect to set inclusion.

**Theorem 1.6.4.** Let $B$ be a subset of a vector space $V$. The following are equivalent:

1. The set $B$ is a basis for $V$;
2. The set $B$ is a minimal generating set for $V$;
3. The set $B$ is a maximal linearly independent subset of $V$.

*Proof.* Definition 1.5.2 immediately shows that the conditions (1) and (2) are equivalent. 
We now show that the conditions (2) and (3) are equivalent. If $B$ is a basis for $V$, then $\operatorname{span}(B) = V$ and $B$ is linearly independent. By Theorem 1.5.5, every superset of $B$ not equal to $B$ is linearly dependent. Hence $B$ is maximal. 
Conversely, suppose that $B$ is a maximal linearly independent subset of $V$. Then, by Theorem 1.5.5, $v\in \operatorname{span}(B)$ for all $v\in V\setminus B$. Hence $V\setminus B\subseteq \operatorname{span}(B)$. Since we also have $B\subseteq \operatorname{span}(B)$, $\operatorname{span}(B)=V$. <span class="qed">$\square$</span>



Thus, a basis can be obtained conceptually in two opposite ways: by removing redundant vectors from a generating set, or by adjoining vectors to a linearly independent set until no further extension is possible. Both processes seek the same kind of generating set.
A basis provides an unambiguous representation of every vector. Generating guarantees that a representation exists, while linear independence ensures that its coefficients are uniquely determined.

**Theorem 1.6.5.** Let $B=\{v_1,\ldots,v_n\}$ be a subset of a vector space $V$ over a field $F$. Then $B$ is a basis for $V$ if and only if every $v\in V$ has a unique representation

$$
v=a_1v_1+\cdots+a_nv_n
$$

for some scalars $a_1,\ldots,a_n\in F$. 



Consequently, the choice of a basis provides a correspondence between vectors of $V$ and tuples of scalars in $F^n$.

**Exchange and replacement.** Although a basis provides unique representations, the basis itself need not be unique. Different sets of vectors may generate the same vector space without redundancy. We therefore turn to the question of how one basis can be modified while preserving its defining properties.
The exchange property of span provides the underlying mechanism. If a new vector can be generated using an existing basis, then certain basis vectors may be replaced by that vector without changing the generated space. Linear independence determines which replacements preserve the basis property.

**Theorem 1.6.6.** Let $B$ be a basis for a vector space $V$, and let $v\in V$ and $b\in B$. If

$$
v\notin\operatorname{span}(B\setminus\{b\}),
$$

then

$$
(B\setminus\{b\})\cup\{v\}
$$

is also a basis for $V$.

Equivalently, the replacement is possible whenever $b$ has a nonzero coefficient in the unique representation of $v$ with respect to $B$.


The basis exchange theorem concerns the replacement of a single vector. A more general question arises when we wish to introduce several linearly independent vectors into a finite generating set. Can the new vectors replace existing generators without losing the ability to generate the entire space? More importantly, how many independent vectors can a finite generating set accommodate?
The following theorem answers both questions. It extends the idea of exchange from individual vectors to finite sets and establishes a fundamental comparison between generating and linear independence.

**Theorem 1.6.7 (Replacement Theorem).** Let $V$ be a vector space, let $S=\{w_1,\ldots,w_n\}$ be a generating set for $V$, and let $T=\{v_1,\ldots,v_m\}$ be a linearly independent subset of $V$. Then $m\le n$. Moreover, there exists a subset $R\subseteq S$ containing exactly $m$ vectors such that

$$
\operatorname{span}((S\setminus R)\cup T)=V.
$$



The theorem has two significant consequences. First, a linearly independent set cannot contain more vectors than a finite generating set for the same space. Second, the vectors of a linearly independent set can replace an equal number of generators while preserving generating.
The replacement theorem does not require the original generating set to be linearly independent. Consequently, the resulting generating set need not itself be a basis. Nevertheless, in a finitely generated vector space, these results allow us to establish the existence of bases and to extend linearly independent sets to bases.

**Corollary 1.6.8.** Let $V$ be a vector space with a finite generating set $S$. Then the following hold:

1. The set $S$ contains a basis for $V$.
2. Every linearly independent subset $T$ of $V$ is finite and can be extended to a basis for $V$ by adjoining suitable vectors from $S$.



**The Cardinalities of bases.** We have now established that a finitely generated vector space admits bases and that an arbitrary linearly independent set can be completed to one. However, these conclusions leave an important question unanswered: can two bases for the same vector space contain different numbers of vectors?
The replacement theorem provides the key to answering this question. Since either basis is both a generating set and a linearly independent set, the theorem can be applied with their roles interchanged. This leads to the invariance of the number of basis vectors.

**Theorem 1.6.9.** Let $V$ be a vector space that has a finite generating set. Then all bases for $V$ are finite and have the same cardinality.


This result makes it possible to compare generating sets and linearly independent sets against a common standard. In particular, once the number of vectors in a basis is known, it determines both the maximum possible size of a linearly independent set and the minimum possible size of a finite generating set.

**Corollary 1.6.10.** Let $V$ be a vector space with a basis containing exactly $n$ vectors. Then:

1. Every linearly independent subset of $V$ contains at most $n$ vectors.
2. Every finite generating set for $V$ contains at least $n$ vectors.
3. A subset $S\subseteq V$ containing exactly $n$ vectors is a basis for $V$ if and only if it is linearly independent, or equivalently, if and only if it spans $V$.



**The dimension of a vector space.** We began by asking how economically a vector space can be generated. The concept of a basis answered this question in terms of minimal generating sets and maximal linearly independent sets. The replacement theorem then revealed a stronger fact: in a finitely generated vector space, every basis contains the same number of vectors, regardless of which vectors are chosen.
Thus, although the choice of a basis is generally not unique, its number of elements is determined by the vector space itself. This allows us to assign a well-defined numerical invariant to every finitely generated vector space, measuring the number of independent generators needed to describe it. This invariant is called the *dimension* of the vector space.
