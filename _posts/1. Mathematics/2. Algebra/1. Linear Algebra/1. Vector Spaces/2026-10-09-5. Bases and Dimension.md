The notion of linear dependence allows us to identify redundancy in a generating set. This naturally raises a question: can we generate an entire vector space without any redundancy? Such a generating set would have two essential properties. It would span the whole space, so that every vector can be generated, and it would be linearly independent, so that removing any one of its vectors would reduce the span. A set satisfying both conditions is called a basis.

**Definition 1.5.1.** Let $V$ be a vector space. A subset $S$ of $V$ is called a *basis* for $V$ if $\operatorname{span}(S) = V$ and $S$ is linearly independent.

**Example 1.5.2.** In the vector space $F_n[x]$, the set $\{1,x,x^2,\ldots,x^n\}$ is a basis—the *standard basis* for $F_n[x]$. While $F_n[x]$ has a finite basis, in $F[x]$, the infinite set $\{1,x,x^2,\ldots\}$ is a basis.

**Theorem 1.5.3.** Let $V$ be a vector space and $v_1,\ldots,v_n$ be distinct vectors in $V$. Then, $B=\{v_1,\ldots,v_n\}$ is a basis for $V$ if and only if each vector in $V$ can be uniquely expressed as a linear combination of vectors in $B$.
