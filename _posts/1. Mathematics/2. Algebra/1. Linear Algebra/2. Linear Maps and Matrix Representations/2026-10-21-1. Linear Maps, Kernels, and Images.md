**Definition 2.1.1.** Let $V$ and $W$ be vector spaces over the same field $F$. A function $f\colon V\to W$ is called a *linear map* from $V$ to $W$ if for all $u,v\in V$ and $a\in F$ the following conditions hold: 
1. $f(u+v)=f(u) +f(v)$ (*additivity*); 
2. $f(av) = af(v)$ (*homogeneity* of degree $1$).

The set of all linear maps from $V$ to $W$ is denoted by $\operatorname{Hom}(V,W)$.
If $f\colon V \to V$ is a linear map, then it is called a *linear operator* on $V$. The set of all linear operators on $V$ is denoted by $\operatorname{End}(V)$.

**Proposition 2.1.2.** Let $V$ and $W$ be vector spaces over $F$, and let $f\colon V \to W$ be a function.
1. If $f$ is linear, then $f(0_V)=0_W$.
2. If $f$ is linear, then $f(u-v)=f(u)-f(v)$ for all $u,v\in V$.
3. The function $f$ is linear if and only if $f(au+v)=af(u)+f(v)$ for all $u,v\in V$ and $a\in F$.
4. The function $f$ is linear if and only if, for finite set $I$ and indexed families $\{v_i\}_{i\in I}$ in $V$ and $\{a_I\}_{i\in I}$ in $F$, we have
   
   $$ f\lowparen{\sum_{i\in I}a_iv_i} = \sum_{i\in I}a_if(v_i).$$
