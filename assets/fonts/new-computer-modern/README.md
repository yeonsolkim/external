New Computer Modern web fonts
=============================

These WOFF2 files are lossless web-font conversions of the New Computer Modern
10 OpenType fonts, version 7.1.1:

- `NewCM10-Regular.otf`
- `NewCM10-Italic.otf`
- `NewCM10-Bold.otf`
- `NewCM10-BoldItalic.otf`

New Computer Modern is maintained by Antonis Tsolomitis and distributed by
CTAN as the `newcomputermodern` package. The fonts are redistributed under the
GUST Font License included in this directory.

Upstream: https://ctan.org/pkg/newcomputermodern
