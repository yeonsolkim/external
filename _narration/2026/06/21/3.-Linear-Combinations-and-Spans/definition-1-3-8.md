Definition 1.3.8. An operator closure on the collection of subsets of a set X is called a closure operator on X if it satisfies the following axioms: For all S and T contained in X, property one: S is contained in the closure of S; closure is extensive. Property two: if S is contained in T, then the closure of S is contained in the closure of T; closure is monotone. Property three: the closure of the closure of S equals the closure of S; closure is idempotent.
