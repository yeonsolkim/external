Example 1.3.6. Let n be a nonnegative integer. The polynomial subspace F n of x from Example 1.2.4 has the finite generating set F n of x equals the span of the set consisting of one, x, and so on, up to x to the n.

The space of all polynomials has the infinite generating set F of x equals the span of the set of x to the k such that k belongs to the nonnegative integers.

A polynomial p of x equals a zero plus a one times x, and so on, up to a m times x to the m, however, uses only finitely many of these generators. Even when a generating set is infinite, each vector in its span is a finite linear combination; no infinite sums are included in the definition of span.
