Example 1.2.5. Let C R R denote the set of all continuous real-valued functions defined on R. Since constant functions are continuous functions, the zero function belongs to C R R. Let f and g belong to C R R. Since f plus g is continuous function, f plus g belongs to C R R. Let f belong to C R R and c belong to R. Since c f is a continuous function, c f belongs to C R R. Theorem 1.2.2 shows C R R is a subspace of R to the R.
