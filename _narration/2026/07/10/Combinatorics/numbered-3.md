3. Multiplication rule.

A process is a trial that is completed in successive stages, whose outcome is called the complete outcome. We let A be the event of the first stage and B the event of the second stage, with size of A equals m, and size of B equals n.

The event “A occurs and then B occurs” is denoted by A then B. Suppose that x records the first-stage outcome and y records the second-stage outcome. Since each of the m possible values of x can be paired with each of the n possible values of y, the size of A then B equals the size of A times the size of B equals m times n.

This formula is called the multiplication rule. The multiplication rule extends to any finite number of stages. If a process consists of k successive stages, and each event A i of the i-th stage has n i possible outcomes, then the event A one through A k can occur in n one times n two times and so on up to n k ways.
