1. Trials and outcomes.

An outcome is one particular possible result of the trial. The sample space, usually denoted by omega, is the set of all possible outcomes. An event is a subset of the sample space. For example, if one die is rolled, the event that an even number appears is A equals the set 2, 4, 6, contained in omega.

The statement “event A occurs” means that the actual outcome of the trial belongs to A. Thus, if the actual outcome is 4, then A occurs; if the actual outcome is 5, then A does not occur. Accordingly, the statement “event A can occur in m ways” means that A contains m possible outcomes: the size of A equals m.

For instance, the number of ways event A equals the set 2, 4, 6 can occur is 3 because there are three outcomes that make A occur.
