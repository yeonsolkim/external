Proof. The forward implication follows from Theorem 3.3.5, part one. Conversely, suppose the sequence x n is Cauchy. Let E m equal the set of all x n such that n is greater than or equal to m. Then we have the diameter of E m naught is less than one for some m naught in the positive integers. Since the range, the set of all x n such that n is greater than or equal to one, is the union of E m naught and the finite set x one through x sub the quantity m naught minus one, so the range is bounded. Thus the set of all x n such that n is greater than or equal to one is contained in I for some k-cell I. Since I is compact, Theorem 3.3.5 completes the proof. This completes the proof.
