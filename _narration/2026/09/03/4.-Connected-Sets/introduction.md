2.4 Connected Sets.

We now focus on the fact that the Cantor set has gaps at every scale: given any x in C and any r greater than zero, no matter how small r is, the neighborhood, the open interval from x minus r to x plus r, contains some open interval that does not belong to C. Thus, if we zoom in around any point of the Cantor set, the set never starts looking like a solid interval. To express the property of a set forming one global piece, we introduce connectedness.
