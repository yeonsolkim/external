Theorem 3.2.3. If the sequence x n is a sequence of points in a compact metric space M, then some subsequence of the sequence x n converges in M.

Proof. If the range of the sequence is finite, then there is x in the range of the sequence and a sequence n k with n one less than n two, and so on, such that x sub n one equals x sub n two, equals, and so on, equals x.

The subsequence x sub n k converges to x. If the range of the sequence is infinite, Theorem 2.2.17 shows that the range of the sequence has a limit point x in M. Since every open ball of x meets the range of the sequence, so we may obtain a sequence n k with n one less than n two, and so on, such that d of x sub n k and x is less than one over k. Then, the subsequence x sub n k converges to x. This completes the proof.
