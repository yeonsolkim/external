Theorem 3.2.3. If x n is a sequence of points in a compact metric space M, then some subsequence of x n converges in M.

Proof. If the set of terms x n is finite, then there is x in the set of terms x n and a sequence n k with n one less than n two, and so on, such that x n one equals x n two, and so on, equals x.

The subsequence x n k converges to x. If the set of terms x n is infinite, Theorem 2.2.17 shows that the set of terms x n has a limit point x in M. Since every open ball of x meets the set of terms x n, so we may obtain a sequence n k with n one less than n two, and so on, such that d of x n k and x is less than one over k. Then, the subsequence x n k converges to x. This completes the proof.
