Theorem 3.4.6. Let x n be a sequence in R and let x in R. Then x n converges to x if and only if the limit superior of x n equals the limit inferior of x n equals x.

Proof. Let A be the set of all extended subsequential limits of x n. If x n tends to x then every subsequential limit of x n is x. Hence A equals the set containing x, so that the maximum of A equals the minimum of A equals x. Suppose, conversely, that the upper limit and lower limit of x n are both x. Then for any epsilon greater than zero, eventually x minus epsilon is less than x n, which is less than x plus epsilon, by Theorem 3.4.5. That is, the absolute value of x n minus x is less than epsilon. Hence x n tends to x. This completes the proof.
