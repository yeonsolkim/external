Example 3.4.4. Let x n be a sequence in R such that the set of x n such that n is greater than or equal to one equals the rationals. Let y in R be given. Suppose n one is less than n two, and so on up to n sub k minus one, have been chosen. Since the set x one through x sub n sub k minus one is finite and the open interval from y minus one over k to y plus one over k has infinitely many rationals, there is a rational q which is not in the set x one through x sub n sub k minus one but belongs to the interval. Since q appears in x n at least once, there exists n k greater than n sub k minus one such that x sub n k equals q. In this way, we obtain a subsequence x sub n k that converges to y. Since y was arbitrary, every real number is a subsequential limit. Let A be the set of all extended subsequential limits of x n. Since the supremum of A is greater than or equal to the supremum of R, by Theorem 3.4.3, the limit superior of x n equals the supremum of A, which equals plus infinity. Similarly, the limit inferior of x n equals the infimum of A, which equals minus infinity. While Theorem 3.4.3 describes the values attained along suitable subsequences, the tail formulation gives useful bounds for the entire sequence.
