Proof. Let A be the set of all extended subsequential limits of x n. If x n converges to x, then every subsequential limit of x n is x. Hence A equals the set containing x, so that the maximum of A equals the minimum of A equals x. Suppose, conversely, that the limit superior and limit inferior of x n are both x. Then for any epsilon greater than zero, eventually x minus epsilon is less than x n, which is less than x plus epsilon, by Theorem 3.4.5. That is, the absolute value of x n minus x is less than epsilon. Hence x n converges to x. This completes the proof.
