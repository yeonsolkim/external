Example 3.4.4. Let x n be a sequence in R such that the set of x n such that n is greater than or equal to one equals Q. Let y in R be given. Suppose n one is less than, and so on, up to n sub the quantity k minus one have been chosen. Since the set consisting of x one through x sub n sub the quantity k minus one is finite and the open interval from y minus one over k to y plus one over k has infinitely many rationals, there is a rational q which is not in the set consisting of x one through x sub n sub the quantity k minus one but belongs to the interval. Since q appears in x n at least once, there exists n k greater than n sub the quantity k minus one such that x sub n k equals q. In this way, we obtain a subsequence x sub n k that converges to y. Since y was arbitrary, every real number is a subsequential limit. Let A be the set of all extended subsequential limits of x n. Since supremum A is greater than or equal to supremum R, by Theorem 3.4.3, we have lim sup of x n equals supremum A, which equals plus infinity.

Similarly, lim inf of x n equals infimum A, which equals minus infinity.
