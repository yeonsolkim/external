Theorem 3.4.5. Let x n be a sequence in R and let y belong to R.

First, if y is greater than the lim sup of x n, then eventually x n is less than y. Second, if y is less than the lim inf of x n, then eventually x n is greater than y.

Proof. First, let the set S be the set of every supremum s k for the k-th tail. Since y is greater than the infimum of the set S, y is not a lower bound for the set S. So there exists k naught such that s sub k naught is less than y. Then y is an upper bound for the k naught-th tail. Since s k is monotonically decreasing, n greater than or equal to k naught implies x n is less than y. Second, let the set T be the set of every infimum t k for the k-th tail. Since y is less than the supremum of the set T, y is not an upper bound for the set T. So there exists k naught such that t sub k naught is greater than y. Then y is a lower bound for the k naught-th tail. Since t k is monotonically increasing, n greater than or equal to k naught implies x n is greater than y. This completes the proof.
