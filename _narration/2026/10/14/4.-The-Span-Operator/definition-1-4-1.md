Definition 1.4.1. An operator c l on the collection of subsets of a set X is called a closure operator on X if it satisfies the following axioms: For all S and T contained in X, first, extensive: S is contained in c l of S. Second, monotone: if S is contained in T, then c l of S is contained in c l of T. Third, idempotent: c l of c l of S equals c l of S.
