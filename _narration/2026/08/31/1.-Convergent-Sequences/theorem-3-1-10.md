Theorem 3.1.10. Let x and y be real numbers.

First, the limit as n goes to infinity of the n-th root of n equals one.

Second, if x is greater than zero, then the limit as n goes to infinity of one over n to the x equals zero.

Third, if x is greater than zero, then the limit as n goes to infinity of the n-th root of x equals one.

Fourth, if x is greater than zero, then the limit as n goes to infinity of n to the y over the quantity one plus x, to the n, equals zero.

Fifth, if the absolute value of x is less than one, then the limit as n goes to infinity of x to the n equals zero.
