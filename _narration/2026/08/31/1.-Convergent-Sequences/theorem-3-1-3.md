Theorem 3.1.3. Let the sequence x n be a sequence in a metric space M.

First, the sequence x n converges to x in M if and only if every open ball centered at x contains x n for all but finitely many n.

Second, for x and y in M, if the sequence x n converges to x and to y, then x equals y.

Third, if the sequence x n converges in M, then the sequence x n is bounded.

Fourth, if x in M is a limit point of A contained in M, then there exists a sequence x n in A that converges to x.
