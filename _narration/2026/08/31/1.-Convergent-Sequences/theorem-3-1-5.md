Theorem 3.1.5. Suppose the sequence x n is a monotonic sequence in R. Then, the sequence x n converges in R if and only if it is bounded.

Proof. Suppose x n is less than or equal to x sub n plus one for n equals one, two, three, and so on, and let alpha be the supremum for the set of x n, for n in positive integers. Given epsilon greater than zero, by lemma 1.1.10, there is n naught in positive integers such that x sub n naught belongs to the interval from alpha minus epsilon to alpha, open on the left and closed on the right. Then, n greater than or equal to n naught implies the absolute value of alpha minus x n is less than epsilon; hence the sequence x n converges to alpha. The converse follows from item three of Theorem 3.1.3. In the other case, where the sequence x n is monotonically decreasing, the proof is analogous. This completes the proof.
