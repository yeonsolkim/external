Definition 3.1.4. A sequence x n in R is said to be monotonically increasing if x n is less than or equal to x n plus one for n equals one, two, three, and so on, and is said to be monotonically decreasing if x n is greater than or equal to x n plus one for n equals one, two, three, and so on. The sequence x n is said to be monotonic if it is monotonically increasing or monotonically decreasing. We often write x n increases to x if x n is monotonically increasing and x n converges to x. Similarly, we write x n decreases to x if x n is monotonically decreasing and x n converges to x.
