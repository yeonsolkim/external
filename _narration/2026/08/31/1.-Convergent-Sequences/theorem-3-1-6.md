Theorem 3.1.6. Suppose x n and y n are sequences in C. If the limit as n goes to infinity of x n equals x and the limit as n goes to infinity of y n equals y, then the following hold: First, the limit as n goes to infinity of the quantity x n plus y n equals x plus y. Second, the limit as n goes to infinity of c x n equals c x, for any c in C. Third, the limit as n goes to infinity of x n y n equals x y. Fourth, if x n is not equal to zero and x is not equal to zero, then the limit as n goes to infinity of one over x n equals one over x.
