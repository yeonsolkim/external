Theorem 3.1.8. Suppose x n is a sequence in R k and the point x n equals x one n through x k n. Then, x n converges to the point x equals x one through x k, if and only if the limit as n tends to infinity of x i n equals x i, for i equals one, two, and so on, up to k.
