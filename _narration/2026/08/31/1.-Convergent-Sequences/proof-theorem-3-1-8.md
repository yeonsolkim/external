Proof. Suppose the point x n converges to the point x. From the definition of the norm in R k, we have the absolute value of x i n minus x i is less than or equal to the norm of x n minus x, for each i from one to k and n in the positive integers. Hence, given epsilon greater than zero, there exists n naught in the positive integers such that n greater than or equal to n naught implies the absolute value of x i n minus x i is less than epsilon. Therefore x i n converges to x i for each i from one to k. Conversely, suppose x i n converges to x i for each i from one to k. Given epsilon greater than zero, there exists n naught i in the positive integers such that n greater than or equal to n naught i implies the absolute value of x i n minus x i is less than epsilon over the square root of k, for each i from one to k. Put n naught equal to the maximum of the set n naught one through n naught k. Then n greater than or equal to n naught implies the norm of x n minus x equals the sum from i equals one to k of the absolute value of x i n minus x i squared, all to the power one half, which is less than epsilon. Since epsilon was arbitrary, the point x n converges to the point x. This completes the proof.
