Definition 2.3.1. Let M be a metric space, and let A be contained in M. A point x in A is said to be isolated in A if the ball of radius r about x, intersect A, equals the set containing x, for some r greater than zero.

That is, x is an isolated point of A if and only if x is not a limit point of A. The set A is said to be perfect if it is closed and has no isolated points. Closedness gives A prime is contained in A, while the absence of isolated points gives A is contained in A prime. Hence A is perfect if and only if A equals A prime.
