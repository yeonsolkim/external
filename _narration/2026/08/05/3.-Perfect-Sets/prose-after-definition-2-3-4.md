At every finite stage it becomes increasingly fragmented, and the surviving intervals shrink toward zero length. Nevertheless, the limiting set has no isolated points and it therefore remains uncountable. We now show that no point of C is isolated. Since each C n is compact and C sub n plus one is contained in C n, Corollary 2.2.12 shows that C is nonempty. Moreover, C is closed as an intersection of closed sets. Fix x in C and r greater than zero. At the n-th stage, x lies in one of the component intervals of C n, whose length is three to the minus n. Both endpoints of this interval remain in all later stages and therefore belong to C. Choose an endpoint y n not equal to x. Then zero is less than the absolute value of x minus y n, which is less than or equal to three to the minus n.

For sufficiently large n, we have three to the minus n less than r, and hence y n belongs to the intersection of the punctured ball of radius r about x and C.

Thus every point of C is a limit point of C. Since C is also closed, it is perfect. Theorem 2.3.3 now shows that C is uncountable.
