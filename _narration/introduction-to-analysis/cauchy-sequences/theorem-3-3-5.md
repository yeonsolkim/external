Theorem 3.3.5. Let the sequence x n be a sequence in a metric space M.

First, if the sequence x n converges in M, then the sequence x n is a Cauchy sequence. Second, if M is compact and the sequence x n is a Cauchy sequence, then the sequence x n converges in M.
