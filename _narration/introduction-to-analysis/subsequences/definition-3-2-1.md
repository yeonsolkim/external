Definition 3.2.1. Let M be a metric space. Given a sequence x n, consider a sequence n k in positive integers, such that n one is less than n two, which is less than n three, and so on. Then the sequence x n k, which maps k to x n k, is called a subsequence of x n. If x n k converges, its limit is called a subsequential limit of x n.
