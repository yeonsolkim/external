Theorem 3.1.6. Suppose x n and y n are sequences in C. If the limit as n tends to infinity of x n equals x and the limit as n tends to infinity of y n equals y, then the following hold: First, the limit as n tends to infinity of the quantity x n plus y n equals x plus y. Second, for any c in C, we have the limit as n tends to infinity of c times x n equals c times x. Third, the limit as n tends to infinity of x n times y n equals x times y. Fourth, if x n is not equal to zero and x is not equal to zero, then the limit as n tends to infinity of one over x n equals one over x.
