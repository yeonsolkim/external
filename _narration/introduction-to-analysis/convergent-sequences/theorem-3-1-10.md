Theorem 3.1.10.

First, if x is greater than zero, then the limit as n tends to infinity of one over n to the x equals zero.

Second, if x is greater than zero, then the limit as n tends to infinity of the n-th root of x equals one.

Third, the limit as n tends to infinity of the n-th root of n equals one.

Fourth, if x is greater than zero and y belongs to R, then the limit as n tends to infinity of n to the y, over the quantity one plus x to the n, equals zero.

Fifth, if the absolute value of x is less than one, then the limit as n tends to infinity of x to the n equals zero.
