Definition 3.4.1. Let the sequence x n be a sequence in R. If for every y in R there is n naught in the positive integers such that n is greater than or equal to n naught, implies x n is greater than or equal to y, then we write x n tends to plus infinity, or the limit as n tends to infinity of x n, equals plus infinity. Similarly, if for every y in R there is n naught in the positive integers such that n is greater than or equal to n naught, implies x n is less than or equal to y, then we write x n tends to minus infinity, or the limit as n tends to infinity of x n, equals minus infinity. A number x in the extended real line is called the extended limit of the sequence x n if x n tends to x, and is called an extended subsequential limit of the sequence x n if x sub n k tends to x, for some subsequence x sub n k.
