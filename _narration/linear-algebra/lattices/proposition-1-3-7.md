Proposition 1.3.7. Given a semilattice S with join, there is a unique order less than or equal to on S which makes x join y the supremum for the set x, y for all x and y in S. Conversely, suppose that S is a poset and any pair of two elements of S has a supremum. If we write the supremum for the set x, y as x join y, and regard join as a binary operation on S, then S with join is a semilattice.
