A function f is an order isomorphism if and only if it is a lattice isomorphism. On the other hand, a lattice homomorphism being monotone, an monotone map between lattices need not preserve joins or meets. Nevertheless, the extremal properties of these operations impose certain inequalities that every such map must satisfy.
