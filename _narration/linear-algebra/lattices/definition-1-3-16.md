Definition 1.3.16. Let L be a lattice with the least element hat zero. A function rho from L to the nonnegative integers is called a rank function on L if it satisfies the following: One: rho of hat zero equals zero. Two: rho of y equals rho of x plus one whenever x is covered by y.

A lattice is called graded if it admits a rank function.
