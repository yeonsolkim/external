Proof. Let n equal the cardinality of C, and regard C as a poset with the induced order. Since C is a finite chain, every element x in C other than its maximum has an immediate successor in C, namely the least element of the set of y in C such that y is greater than x. Furthermore, this immediate successor is unique. Indeed, if both y and z cover x and y is not equal to z, either y is less than z or z is less than y, contradicting the covering relation. Since each of the n minus one nonmaximum elements is the lower element of exactly one covering pair in C, the length of C equals n minus one. This completes the proof.
