Example 1.2.18. Let V equal R squared and W equal the set of all points with coordinates t and zero, with t in R, the horizontal axis. For the point with coordinates a and b in V, the point with coordinates a and b, plus W, equals the set of all points with coordinates a plus t and b, with t in R, which equals the set of all points with coordinates t and b, with t in R.

Thus each coset is a horizontal line, determined by its height b. If L b denotes the line at height b, then the operations in V modulo W become L b plus L c equals L sub the quantity b plus c, and lambda L b equals L sub lambda b.
