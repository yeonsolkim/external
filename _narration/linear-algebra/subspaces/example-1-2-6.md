Example 1.2.6. An n by n matrix A is called a diagonal matrix if A sub i j equals zero whenever i is not equal to j. Let W be the set of all n by n diagonal matrices. Since the i j entry of O equals zero for all i and j, O belongs to W. Let A and B belong to W. If i is not equal to j, then the i j entry of A plus B equals A sub i j plus B sub i j, which equals zero plus zero, which equals zero. Thus A plus B belongs to W. Let A belong to W and c belong to F. If i is not equal to j, then the i j entry of c A equals c times A sub i j, which equals c times zero, which equals zero times c, which equals zero. Thus c A belongs to W. Theorem 1.2.2 shows that W is a subspace of n by n matrices over F.
