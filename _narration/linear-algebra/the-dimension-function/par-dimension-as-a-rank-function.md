Dimension as a rank function. Now we are ready to consider dimension as a function. For a finite-dimensional vector space, the dimension function is a rank function on the subspace lattice. This allows us to establish fundamental properties of dimension easily, including the Grassmann’s dimension formula. Furthermore, by composing the dimension function with the span map, we obtain a function that assigns a rank to every subset of V. This induced rank function is generally only submodular, reflecting the fact that the span map preserves joins but need not preserve meets. Throughout the remainder of this section, we assume that V is finite-dimensional, with dimension of V is n.
