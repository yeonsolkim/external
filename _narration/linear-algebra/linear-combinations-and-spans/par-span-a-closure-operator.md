Span: A closure operator. A function maps each input to the output. Viewing it as an operator emphasizes how it transforms mathematical objects. When an operator maps a collection of objects to itself, we can compose it with itself and apply it repeatedly. This leads us to study how an object changes under one application, what happens under successive applications, and which objects remain unchanged. Span acts on subsets of a vector space V, transforming each subset into the smallest subspace containing it. We can study this transformation through its relation to inclusion, its behavior under iteration, and its fixed points. We begin by introducing the general notion of a closure operator.
