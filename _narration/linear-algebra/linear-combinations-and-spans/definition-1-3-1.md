Definition 1.3.1. Let M, plus, zero in M, be a commutative monoid, and let the family x i, for i in I, be a family of elements of M indexed by a finite set I. The sum of this family is defined recursively by: the sum over i in the empty set of x i equals zero in M, and the sum over i in I of x i equals x j plus the sum over i in I minus the set containing j of x i, if j belongs to I.

The sum of a family indexed by the empty set is called the empty sum. When I equals the set one through n, we also write the sum as the sum from i equals one to n of x i.
