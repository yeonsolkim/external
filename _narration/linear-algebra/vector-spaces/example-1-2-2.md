Example 1.2.2. Let F be a field. An object of the form a one through a n with a one, a two, and so on, up to a n in F is called an n-tuple with entries from F. The set of all n-tuples from F is denoted by F n. We give F n the operations of coordinate-wise addition and scalar multiplication. For u equals a one through a n in F n, v equals b one through b n in F n, and c in F, we have u plus v equals a one plus b one, a two plus b two, and so on, up to a n plus b n, and c u equals c a one, c a two, and so on, up to c a n.

Then, F n is a vector space over F. A row vector a one through a n may be written as a column vector whose entries are a one, a two, and so on, up to a n.
