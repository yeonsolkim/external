Example 1.2.4. Let S be a nonempty set and F be a field, and let F S denote the set of all functions from S to F. We give F S the operations of point-wise addition and scalar multiplication: For f and g in F S and c in F, the function f plus g at x equals f of x plus g of x, and the function c f at x equals c times f of x, for all x in S. Two functions f and g are equal if f of x equals g of x for all x in S, and the zero function is defined by zero at x equals zero for all x in S. We can see that F S is a vector space over F.
