Example 1.2.3. An m by n matrix with entries from a field F is a rectangular array of the form the matrix whose first row is a one one, a one two, and so on, up to a one n; whose second row is a two one, a two two, and so on, up to a two n; and so on, up to the m-th row, a m one, a m two, and so on, up to a m n, where each a i j is an element of F, called an entry of the matrix. We call the entries a i j with i equals j the diagonal entries. The diagonal entries compose the main diagonal of the matrix. If every entry equals zero, the matrix is called the zero matrix, denoted by O. The entries a i one through a i n compose the i-th row of the matrix, and the entries a one j through a m j compose the j-th column of the matrix. If the number of rows and columns are equal, the matrix is called a square matrix. The set of all m by n matrices from F is denoted by matrices m by n over F. We give matrices m by n over F the following operations of matrix addition and scalar multiplication. For A and B in matrices m by n over F and c in F, the i j entry of A plus B equals A i j plus B i j, and the i j entry of c A equals c times A i j, for i from one to m and j from one to n. Then matrices m by n over F is a vector space over F.
