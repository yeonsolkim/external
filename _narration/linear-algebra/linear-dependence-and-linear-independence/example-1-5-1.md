Example 1.5.1. Let the vector x equal one zero and y equal zero one in R two, and consider S equal to the set consisting of the vector x, the vector y, and the vector x plus the vector y. Then we have the span of the set consisting of the vector x, the vector y, and the vector x plus the vector y, equals the span of the set consisting of the vector x and the vector y, which equals R two.

Thus, removing the vector x plus the vector y from S does not change the subspace generated by S. The vector x plus the vector y is therefore redundant.
