Proof. Let C S equal the set of closed sets C in the collection C such that C contains S. Since the closure of S belongs to C S, we have the first inclusion: the intersection of C S is contained in the closure of S. By Theorem 1.5.4, for all closed sets C in C S, S is contained in C implies that the closure of S is contained in C. Therefore we have the second inclusion: the closure of S is contained in the intersection of C S. This completes the proof.
