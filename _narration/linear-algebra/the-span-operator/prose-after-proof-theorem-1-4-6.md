For a fixed S contained in X, Theorem 1.4.6 also has a pointwise interpretation. The closure c l of S is itself closed, contains S, and is contained in every closed set containing S. Hence c l of S is the minimal closed set containing S. We now show that span is a closure operator on a vector space.
