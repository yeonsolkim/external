Definition 1.4.1. An operator c l on the collection of subsets of a set X is called a closure operator on X if it satisfies the following axioms: for all S and T contained in X, First, extensive: S is contained in the closure of S. Second, monotone: if S is contained in T, then the closure of S is contained in the closure of T. Third, idempotent: the closure of the closure of S equals the closure of S.
