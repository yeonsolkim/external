Proof. Suppose c l is a closure operator on X. Since c l is monotone and idempotent, if S is contained in c l of T, then c l of S is contained in c l of c l of T, which equals c l of T. Since c l is extensive, if c l of S is contained in c l of T, then S is contained in c l of S, which is contained in c l of T. Conversely, suppose star holds for any S and T contained in X. Since c l of S is contained in c l of S, we have S is contained in c l of S; hence c l is extensive. Since c l is extensive, if S is contained in T, then S is contained in c l of T. Then c l of S is contained in c l of T follows from star; c l is monotone. The inclusion c l of c l of S is contained in c l of S follows from c l of S is contained in c l of S by star. Since extensivity gives the reverse inclusion, c l of c l of S equals c l of S; c l is idempotent. This completes the proof.
