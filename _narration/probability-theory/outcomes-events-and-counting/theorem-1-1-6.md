Theorem 1.1.6, Multiplication rule. Let A be the event of the first stage and B the event of the second stage, with the number of ways event A can occur equals m and the number of ways event B can occur equals n. Then we have the number of ways event A then B can occur equals the number of ways event A can occur times the number of ways event B can occur, which equals m times n.
