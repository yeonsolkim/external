Definition 1.1.7. For a positive integer n, the factorial of n is defined by, n factorial equals n times the quantity n minus one, and so on, down to two times one.

We also define zero factorial equals one. To arrange n distinct objects in a row, we have n choices for the first position, n minus one choices for the second position, and so on. By the multiplication rule, the number of ways the process of arrangements can be completed, is n times the quantity n minus one, and so on, down to two times one, equals n factorial.
