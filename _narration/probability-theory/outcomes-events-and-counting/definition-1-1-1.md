Definition 1.1.1. An outcome is one particular possible result of an experiment. The sample space, usually denoted by omega, is the nonempty set consisting of all possible outcomes. An event is a subset of the sample space. For example, if one die is rolled, the event that an even number appears is A equals the set two, four, and six, which is contained in omega.

We say that event A occurs if the actual outcome belongs to A, that is, in set notation, the actual outcome belongs to A.

Thus, if the actual outcome is four, then A occurs; if the actual outcome is five, then A does not occur. Accordingly, the statement “event A can occur in m ways” means that A contains m possible outcomes. In this case, we write the number of elements of A equals m.

For instance, the number of ways event A equals the set two, four, and six can occur is three because there are three outcomes that make A occur.
