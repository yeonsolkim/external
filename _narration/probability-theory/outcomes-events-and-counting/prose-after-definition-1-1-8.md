The first object can be chosen in n ways, the second in n minus one ways, and the r-th in n minus r plus one ways. Hence the number of r-permutations is n P r equals n times the quantity n minus one, and so on, down to the quantity n minus r plus one, which equals n factorial over the factorial of n minus r.

In particular, n P n equals n factorial and n P zero equals one.
