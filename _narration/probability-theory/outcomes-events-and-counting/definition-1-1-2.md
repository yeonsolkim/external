Definition 1.1.2. Let omega be the sample space of an experiment and let A and B be events. The events A and B are said to be disjoint or mutually exclusive, if they cannot occur at the same time. In this case, we write A intersection B equals the empty event.

The complement of A, denoted by A complement, is the event that occurs if and only if A does not occur. The union of A and B, denoted by A union B, is the event that occurs if and only if A or B occurs. For more than two events, we can also define their union: For n events A one through A n, we define the union of them, denoted by A one union, and so on, up to A n, or the union from i equals one to n of A i, to occur if and only if at least one of A one through A n occurs.

The intersection of A and B, denoted by A intersection B, is the event that occurs if and only if A and B occurs. Similarly, we define the intersection of n events A one through A n, denoted by A one intersection, and so on, up to A n, or the intersection from i equals one to n of A i, to occur if and only if all of A one through A n occur.
