The multiplication rule also extends to any finite number of stages. If a process consists of k successive stages, and each event A i of the i-th stage has n i possible outcomes, and every tuple in A one then A two, and so on, up to A k is admissible, then this event can occur in n one times n two, and so on, up to n k ways: the number of ways event A one then A two, and so on, up to A k can occur equals n one times n two, and so on, up to n k.
